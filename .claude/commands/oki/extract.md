基于给予资料，或现有资料，进行思考、总结、提炼，生成知识点，搭建知识链接

## 指令参数

- 可指定为资料地址，**基于资料**提炼，例如：`/oki:extract references/paper.pdf`、`/oki:summary https://www.example.com/article.html`
- 也可以为知识点，**基于目标**从现有资料中提炼，例如：`/oki:extract 胶原蛋白`

若未指定，则尝试从对话上下文自动推断；若表述模糊或存在歧义，必须提示列出可用变更项

## 知识库结构

```bash
openwiki
├── nodes/       # 知识点 - 从「资料记录」提取到的，描述某知识点的页面
├── public/      # 静态资源
├── scripts/     # 执行脚本
├── sources/     # 资料记录 - 对单篇「原始资料」的总结、记录
├── templates/   # 页面模板
├── config.yaml  # 配置文件
├── index.md     # 主页 - 知识库内容索引页
├── log.md       # 变更日志页 - 知识库改动的记录
└── overview.md  # 总览页 - 对知识库的总结
```

## 知识点页面规范

- 根据模板（`templates/node.md`）构建页面
- 以中文为主，专有名词、约定俗称可用英文
- 正文内容按描述的对象，设多级标题分块表达
- 「知识点」的正文内容，概览页的节点描述，都至少包含一个「知识链接」
- 流程图使用 Mermaid
- `aliases`允许空格、特殊符号
- `tags`大驼峰，不留空格，不用除，至少包含一个非数字字符
- 链接使用 `[]()` ，而非`[[wiki-link]]`

## 执行步骤

严格分步骤进行，不可跳步

1. **根据不同情况，准备相关的「资料记录」**
   - 若基于资料，执行`/oki:summary`，为给定的原始资料创建或更新「资料记录」
   - 若基于目标，执行`/oki:query --source`，在知识库内部查找与目标相关的「资料记录」

2. **从「资料记录」中提取知识点，创建或更新「知识点」**
   - 知识点可以是抽象的概念，如：现象、原理、分子、基因、解剖结构、物质、物种、方法、术语、说法等
   - 也可以是具体的实体，如：某人物、某公司、某产品、某项目、某课题、某案例等
   - **不要**基于现有任何「知识点」，仅通过「资料记录」

3. **搭建「知识链接」**
   从正文中寻找，与已有「知识点」相关的表述，创建链接，例如`[III型胶原蛋白](concepts/胶原蛋白.md)功能的核心结构基础，是由[三条α链](concepts/三螺旋结构.md)组成`

4. **若有新页面，更新「总览页」**

5. **页面格式化**  
   执行`npx prettier --write entities/ concepts/ index.md overview.md log.md`
